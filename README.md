## 线路测试应该怎么看

网上关于 BandwagonHost 新加坡 CN2 GIA 的测试，常见指标包括延迟、丢包、回程路由、下载速度和不同运营商表现。第三方测试曾报告过中国大陆不同城市和运营商之间存在明显延迟差异，也有测试显示电信方向经过 CN2 相关路径，而联通、移动方向可能采用不同的国际网络组合。

看测试报告时，建议重点关注以下内容：

1. **测试时间**：白天和晚高峰可能完全不同，单次测试不能代表全天表现。
2. **测试地点**：北京、上海、广州以及不同省份的网络出口存在差异。
3. **运营商类型**：电信、联通、移动的去程和回程可能不是同一条路径。
4. **测试目标**：测速服务器很近，不代表访问你的真实用户也会同样快。
5. **丢包定义**：路由中间节点显示星号，不一定代表最终业务真的丢包，要结合终点数据判断。
6. **业务类型**：网页、视频、远程桌面、游戏和文件下载对网络质量的要求不同。

比较稳妥的做法是先购买最低配置，部署一个与真实业务接近的测试环境，再观察几个运营商、不同时间段和实际用户地区的访问情况。不要只因为某篇文章写了一个漂亮的测速数字，就直接预付一年。
